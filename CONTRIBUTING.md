# Mitmachen

Schön, dass du helfen willst! Issues, PRs und Diskussionen laufen auf Deutsch.

1. **Erst ein Issue**, dann Code – außer bei Tippfehlern. So klären wir vorher, ob die Änderung passt.
2. Fehlerberichte mit **Diagnose** aus der App (Voraussetzungen → Diagnose kopieren).
3. Code-Stil, Tests und Prüfschritte stehen in [AGENTS.md](AGENTS.md) – sie gelten für Menschen und Agenten gleichermaßen.
4. Ein PR löst ein Issue (`Closes #…`) und ist grün in CI.

Mit einem Beitrag stellst du ihn unter die [Apache-2.0-Lizenz](LICENSE) des Projekts.
